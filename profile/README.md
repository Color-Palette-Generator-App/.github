## 🚀 Summary
Color Palette Generator for Windows is a smart palette creator that helps designers land on the right colors quickly. Its random mode uses intelligent color pairing to suggest balanced schemes on demand, its image mode reads the key colors out of any photo you load, and its hex mode expands a single value into a full palette. When a set of colors clicks, the hex codes export in one click, and because the app runs on your desktop, your work stays on your machine.
